# numbers-ascii-go

Numbers are great...



For normal numbers run:
```bash
curl https://num-ascii-go.onrender.com/num
```
For ASCII numbers run:
```bash
curl https://num-ascii-go.onrender.com/numascii
```

## Running locally

